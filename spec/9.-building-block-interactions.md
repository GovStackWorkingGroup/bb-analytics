# 9. Building Block Interactions

How the Analytics Building Block interacts with other GovStack Building Blocks — upstream dependencies, integration layer, and downstream recipients.

{% hint style="info" %}
🔗 **Seven Building Blocks, one integration fabric.** Most interactions flow through the Information Mediator.
{% endhint %}

The Analytics Building Block interacts with the following GovStack Building Blocks:

| Building Block | Interaction Type | Description |
| -------------- | ---------------- | ----------- |
| Identity / Access Management BB | Upstream dependency | Provides federated SSO authentication tokens validated by the Analytics BB and manages role assignments reflected in the Analytics BB policy engine. |
| Consent BB | Upstream dependency (selective) | Manages consent records and status; the Analytics BB reads consent status for PBAC enforcement where personal data is involved. It does not perform PII anonymisation. |
| Information Mediator BB | Integration layer | Provides the secure inter-BB messaging fabric used to receive data (and, upstream, to pseudonymise PII), and to dispatch workflow-trigger and publication signals downstream. |
| Digital Registries BB | Upstream data source | Authoritative source for transactional entity data; registries deliver harmonised records to the Analytics BB via the Information Mediator. For climate deployments these include climate registries (indicators, GHG inventory, sectors). |
| Scheduler BB | Orchestration support | Triggers time-based pipeline runs and scoring/reconciliation jobs within the Analytics BB. |
| Workflow BB | Downstream recipient | Receives execution signals from the Analytics BB proactive-trigger module to initiate automated service-delivery or review workflows. |
| Messaging BB | Downstream notification | Receives notification dispatch requests following proactive-trigger or data-publication events. |

When the Building Block is deployed for a climate use case, upstream data sources reached through the Information Mediator include national GHG-inventory and statistics systems and Earth-observation providers; downstream consumers include NDC-tracking dashboards and transparency-reporting services.
