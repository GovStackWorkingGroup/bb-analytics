# 1. Version History

Version history for the GovStack Analytics Building Block Technical Specification.

This page tracks how the Analytics Building Block Technical Specification has evolved since its first draft.

{% hint style="success" %}
✅ **Current version: 0.3** — published September 2026.
{% endhint %}

| Version | Authors                                | Date           | Comment |
| ------- | -------------------------------------- | -------------- | ------- |
| 0.1     | ITU                                    | June 2026      | First draft — adapted from National Data Platform technical specifications. |
| 0.2     | ITU                                    | August 2026    | Second draft. Resolved review comments (abbreviation glossary; cross-layer data validation, cleaning and reconciliation; corrected attribution of PII pseudonymisation away from the Consent BB). Added climate data-type coverage — geospatial / Earth-observation assets, GHG inventory and indicator time series, and multi-source divergent-evidence reconciliation with governed human review — informed by the Climate Data Building Block ToR (v0.2) and the NDC data workflows. |
| 0.3     | Putri Wikie Novianti (INA Digital Edu) | September 2026 | Reviewed, assessed, and adapted the draft for an educational context, drawing on insights from the Rapor Pendidikan Indonesia experience.
