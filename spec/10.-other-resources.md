## 10.1 Key Decision Log

| #   | Decision | Rationale | Status |
| --- | -------- | --------- | ------ |
| 001 | Exclude PII anonymisation from Analytics BB scope; perform it in upstream ingestion/registry/Information Mediator layers. | PII pseudonymisation is a data-processing function of the ingestion path, not of the Consent BB, which manages consent records; separating it reduces attack surface and avoids role duplication. | Accepted |
| 002 | Adopt dual-engine query architecture (federated + OLAP). | Decouples heavy exploratory workloads from mission-critical dashboard SLAs. | Accepted |
| 003 | Mandate AST-level security enforcement for AI query synthesis. | Compiler-level enforcement is the only reliable safeguard against LLM-generated SQL bypassing access controls. | Accepted |
| 004 | Prohibit local user credential storage. | Centralising authentication in the Identity / Access Management BB ensures consistent revocation across systems. | Accepted |
| 005 | Require cryptographic audit-log chaining. | Ensures tamper-evident audit trails even for super-administrative accounts. | Accepted |
| 006 | Apply data validation, cleaning and reconciliation as data is promoted across Bronze, Silver and Gold layers. | Data quality must be enforced at layer transitions, not assumed; this is essential for a trustworthy single view. | Accepted |
| 007 | Support multi-source reconciliation with governed human review and "official versus supplementary" designation. | Divergent evidence streams (e.g. national inventories vs satellite) must be reconciled transparently, not averaged; final designation can require a sovereign human decision. | Accepted |
| 008 | Keep the Building Block domain-agnostic while explicitly supporting climate data types (geospatial/EO, GHG inventory and indicator series). | Enables reuse of one generic Analytics BB across sectors, including climate, without forking the specification. | Accepted |

## 10.2 Future Considerations

* Real-time streaming analytics (sub-second ingestion and query against live event streams).
* Federated learning across distributed data silos without centralising data.
* Standardised open-data export compliant with DCAT and SDMX for public data portals.
* Domain-specific AI models grounded for a given sector (e.g. climate) to strengthen reconciliation, mapping and anomaly recommendations — always advisory, with human validation required.
* Differential-privacy mechanisms for publishable aggregate statistics.
* Multi-jurisdiction federated analytics for cross-border policy analysis within agreed governance frameworks.
