# 8. Standards

Standards and frameworks the Analytics Building Block must comply with or align to, including climate-specific standards.

{% hint style="info" %}
📐 **REQUIRED is the floor.** RECOMMENDED and OPTIONAL entries extend it — several of the latter are specific to climate deployments.
{% endhint %}

The Analytics Building Block must comply with or align to the following standards and frameworks. Education-specific standards and national data models apply when the Building Block is deployed for education use cases.

| Standard / Framework | Scope | Applicability |
| -------------------- | ----- | ------------- |
| OpenAPI 3.x | API specification for all external interfaces | REQUIRED |
| OpenID Connect 1.0 / SAML 2.0 | Federated authentication with Identity / Access Management BB | REQUIRED |
| OAuth 2.0 (RFC 6749) | Token-based authorisation for API access | REQUIRED |
| TLS 1.2 / 1.3 | Transport encryption for all inter-BB communications | REQUIRED |
| Apache Parquet / Iceberg / Delta Lake | Open table formats for lakehouse storage | REQUIRED |
| Apache Arrow | In-memory columnar format for analytical processing | RECOMMENDED |
| DCAT v3 (Data Catalogue Vocabulary) | Metadata interoperability for the data catalogue | RECOMMENDED |
| ISO/IEC 11179 | Metadata registries for governed code sets and controlled vocabularies | RECOMMENDED |
| W3C PROV-O | Data provenance and lineage representation | RECOMMENDED |
| UN/CEFACT SDMX 3.0 | Statistical data and metadata exchange (indicators, aggregates) | RECOMMENDED |
| OGC STAC / OGC API / ISO 19115 | Spatio-temporal catalogue and geographic metadata for geospatial and Earth-observation datasets | RECOMMENDED (climate) |
| IPCC 2006 Guidelines & 2019 Refinement | Sectors, categories, gases and methodological tiers for GHG inventory data | OPTIONAL (climate) |
| UNFCCC ETF Common Reporting Tables | Reporting structure for national climate transparency | OPTIONAL (climate) |
| ISO/IEC 27001 | Information security management | RECOMMENDED |
| GovStack Cross-Cutting Requirements | Baseline non-functional requirements for all BBs | REQUIRED |
| GovStack Security & Identity Building Blocks | Security and access-control architecture alignment | REQUIRED |
